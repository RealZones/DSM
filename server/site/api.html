DSM API

Free Dragsim auction house and bazaar prices, worked out from every sale. No key and no sign-up. If you show our numbers, link back to the item's page on DSM.

No keySend a User-Agent that names your project.
100 / minper IP, with bursts of up to 30.
JSONCoins as numbers, times in ms since 1970. Open to browsers (CORS).

Base URL:

https://dsmnet.xyz/api/v1
curl -A "my-dragsim-tool/1.0" https://dsmnet.xyz/api/v1/item/bonemerang

Limits

Each IP gets 100 requests a minute, and can burst up to 30 at once. Past that you get 429 with a Retry-After header in seconds. Answers are cached for 30 seconds and prices update about that often, so polling faster gets you nothing new. Requests without a User-Agent get 400.

Errors

StatusMeaning
400A parameter is wrong, or there is no User-Agent. The body says which.
404No item with that id.
429Slow down. Wait Retry-After seconds.
503Prices are rebuilding after a restart, usually under 30 seconds.
{ "error": "Unknown item: bonemerangg" }

Search

GET/search?q={text}

Items whose name matches, best first, up to 12. Use the entry as the id everywhere else.

{ "items": [
    { "entry": "hyper_cleaver", "name": "Hyper Cleaver", "tier": "EPIC" },
    { "entry": "hyperion", "name": "Hyperion", "tier": "LEGENDARY" }
] }

Item price

GET/item/{id}

What a plain copy is worth now, and the numbers behind it. For a bazaar product, bazaar holds the live order book's best bid and ask; otherwise it is null.

{
  "entry": "bonemerang", "name": "Bonemerang", "tier": "LEGENDARY", "npc": 20000000,
  "estimate": {
    "value": 500000000,
    "median": 410000000,
    "lbin": 536000000,  "lbin_live": 5,
    "last_sale": { "price": 500000000, "at": 1794767588031 },
    "volume": 2.67,
    "time_to_sell": 78,
    "insta_sell": 450000000,
    "confidence": "high"
  }
}
FieldWhat it is
valueOur best price for this copy. Use this one.
medianMedian of recent sales of copies like this. Careful, runs low.
lbinCheapest live BIN of this kind. lbin_live is how many are up.
volumeSales per day.
time_to_sellUsual minutes from listing to sale.
insta_sellA price that sells quickly.
confidencehigh or low. Low means few sales; treat it as a guess.

Filters

/history, /sold and /active take these to narrow to copies like yours, for example ?stars=5&recomb=1: rarity, stars, reforge, recomb, hpb, ghpb, aow, sync, enrich, dye, skin, pet_level, pet_item, pet_skin, engine, tank, module. A Tier-Boosted pet keeps its own id with a higher rarity, so pass rarity to keep it apart from plain ones.

Price history

GET/item/{id}/history?range=day|week|month|all

One row per hour (day) or per day (the rest). Takes the same filters.

{ "range": "month", "bazaar": false, "rows": [
    { "t": 1794614400000, "avg": 682375000, "min": 400000000, "max": 1250000000, "vol": 16 },
    { "t": 1794700800000, "avg": 511111111, "min": 350000000, "max": 1500000000, "vol": 9 }
] }

Recent sales

GET/item/{id}/sold?limit=24

Newest first, up to 100. parts lists what was on the copy.

{ "auctions": [
    { "id": "1189c59d-…", "unit": 1500000000, "count": 1, "seller": "Steve", "buyer": "Alex",
      "at": 1794782029699, "parts": ["5 stars", "10 books"] }
] }

Live listings

GET/item/{id}/active

Auctions up right now, cheapest first, up to 60, with end as when each one closes.

Many prices at once

GET/prices?ids=bonemerang,crypt_cache_item

Up to 50 ids in one request, counted as one request. Ids DSM doesn't know are left out of the answer. Any number can be null when there is nothing to go on.

{ "bonemerang": { "now": 536000000, "recent": 500000000, "monthly": 470000000, "volume": 2.67, "bazaar": false } }
nowLowest BIN, or the bazaar's buy price.
recentMedian of clean copies over two days (fourteen when two days hold fewer than three sales).
monthlyMiddle of the last month's daily averages.

Bazaar

GET/bazaar

Every product. Dragsim doesn't publish bazaar sale prices, so DSM reads them off the order book every 30 seconds. bought is sell offers that filled; sold is buy orders that filled.

{ "products": [
    { "entry": "crypt_cache_item", "name": "Crypt Cache",
      "ask": 87999999, "bid": 41000001, "price": 74444442,
      "bought": { "amount": 1733, "average": 72608749 },
      "sold":   { "amount": 19,   "average": 41578950 } }
] }

Status

GET/status

Whether prices are current: ok is false when the last update is over five minutes old.

{ "market_time": 1794828023749, "listings": 943, "ok": true }
